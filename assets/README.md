# Captures à ajouter

Ajoute ici 3 à 5 captures maximum, avec des données de démonstration :

1. Connexion ou création de compte.
2. Espace professionnel et statistiques.
3. Exemple de boutique ou d'annonce.
4. Vue de gestion des boosts ou de la visibilité.

Avant de publier une image, vérifie qu'elle ne contient ni nom réel, numéro de téléphone, e-mail, adresse, jeton, identifiant de paiement, information d'administration ni conversation utilisateur.

Nomme les fichiers de façon descriptive, par exemple `espace-pro-metrics-demo.png`, puis ajoute-les dans le README principal avec un texte alternatif utile.
