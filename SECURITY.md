# Signalement responsable

Ce dépôt ne contient pas le code de production de Flash Market. Il sert uniquement de portfolio public.

Si vous identifiez un problème dans son contenu (donnée personnelle, capture sensible, secret publié par erreur), ouvrez une issue privée ou contactez le propriétaire du profil GitHub avant toute divulgation publique.

Les vulnérabilités concernant l'application de production doivent être transmises à l'équipe responsable via son canal privé ; ne les publiez pas dans les issues de ce dépôt.
